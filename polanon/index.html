PolAnon: maskowanie polskich danych osobowych dla AI

Zamienia PESEL, NIP, IBAN, adresy i polskie imiona w każdym przypadku na tokeny, zanim tekst trafi do modelu, i wstawia prawdziwe dane z powrotem do odpowiedzi.

Wypróbuj w przeglądarce Zobacz na GitHubie
  • 71%danych zamaskowanych w całości na publicznych polskich tekstach (Presidio: 66%)
  • 0zależności w rdzeniu, wystarczy sam Python 3.11+
  • MITotwarte oprogramowanie, za darmo

Jak to działa

Model nie potrzebuje prawdziwych danych klienta, żeby napisać odpowiedź. Wystarczy mu wiedza, że chodzi o osobę, jej PESEL czy numer telefonu:

  1. 1Ty piszeszOdpisz Janowi Kowalskiemu, PESEL 50810112354, tel. 512 345 678, że korekta jest gotowa.
  2. 2Model dostajeOdpisz <OSOBA_1>, PESEL <PESEL_1>, tel. <TELEFON_1>, że korekta jest gotowa.
  3. 3Model odpowiadaSzanowny Panie <OSOBA_1:wołacz>, korekta jest gotowa.
  4. 4Ty widziszSzanowny Panie Janie Kowalski, korekta jest gotowa.

Tabela, która zamienia tokeny z powrotem na dane, nigdy nie opuszcza Twojego komputera ani serwera. Ten sam klient ma ten sam token przez całą rozmowę, a gdy model poprosi o inny przypadek, PolAnon odmieni imię i nazwisko.

Co maskuje

Numery z sumą kontrolną

PESEL, NIP, REGON, dowód osobisty, IBAN i karty płatnicze, sprawdzane sumą kontrolną. KRS i paszport obok etykiety.

Osoby i firmy

Polskie imiona z nazwiskami w każdym przypadku, także małymi literami i bez ogonków. Firmy po formie prawnej: Sp. z o.o., S.A., GmbH, Ltd.

Kontakt i adresy

E-maile, telefony polskie i zagraniczne, adresy, kody pocztowe i ulice tak, jak zapisuje je rejestr TERYT.

Internet i sprzęt

Adresy IP i MAC, linki do profili w LinkedIn czy GitHub razem z nazwą użytkownika.

Sekrety

Klucze API, tokeny i hasła, zanim agent wyśle do modelu plik konfiguracyjny albo log.

Reszta

Numery rejestracyjne i VIN, prawa jazdy, daty urodzenia oraz numery z zagranicznych faktur: VAT UE, Bankgiro, sort code.

Same reguły nie potrzebują żadnego modelu językowego. Z opcjonalnym polskim modelem spaCy (pl_core_news_md) PolAnon rozpoznaje też miejsca, firmy bez formy prawnej i imiona spoza swoich list.

Jak zacząć

1Demo w przeglądarce bez instalacji

Do rozmów z ChatGPT albo Claude na ich stronach. Wklejasz tekst do demo PolAnon, kopiujesz wersję z tokenami do czatu, a odpowiedź wklejasz z powrotem: tokeny wracają jako prawdziwe dane. Demo działa w Twojej przeglądarce i niczego nie wysyła.

2Bramka w Dockerze bez kodu

Do gotowych narzędzi, które rozmawiają z modelem: n8n, Open WebUI, LibreChat, Claude Code i każdego innego, które łączy się przez API OpenAI lub Anthropic. Bramka staje między narzędziem a dostawcą modelu i maskuje każde wywołanie, a odpowiedź oddaje z prawdziwymi danymi.

Terminal
# klucz dostawcy modelu i klucz dla Twoich narzędzi
export POLANON_UPSTREAM_KEY=sk-...
export POLANON_GATEWAY_KEY=$(openssl rand -hex 16)

docker run --rm -p 127.0.0.1:8787:8787 \
    -e POLANON_UPSTREAM_KEY -e POLANON_GATEWAY_KEY \
    ghcr.io/boromat/polanon-gateway:0.3 \
    --upstream https://api.openai.com/v1

W narzędziu ustawiasz adres http://127.0.0.1:8787/v1, a jako klucz API wartość POLANON_GATEWAY_KEY.

3Biblioteka Pythona dla programistów

Do własnej aplikacji, agenta albo potoku RAG: maskujesz przed wywołaniem modelu i przywracasz dane w odpowiedzi.

Terminal
pip install polanon
Python
from polanon import Anonymizer, default_guards

anonymizer = Anonymizer(default_guards(with_ner=False))
result = anonymizer.anonymize_sync(
    "Proszę o korektę faktury dla Jana Kowalskiego, PESEL 50810112354."
)
print(result.anonymized)
# Proszę o korektę faktury dla <OSOBA_1>, PESEL <PESEL_1>.

answer = "Korekta dla <OSOBA_1> jest gotowa."  # tak odpowiedział model
print(Anonymizer.restore(answer, result.mapping))
# Korekta dla Jana Kowalskiego jest gotowa.

Firmie, która potrzebuje po prostu czatu dla zespołu, służy PolGate: firmowy czat z modelami GPT i Claude, zbudowany na PolAnon.

Gdzie się sprawdza

Czat z modelem

SDK Anthropic, OpenAI albo model lokalny. Odpowiedź wraca z danymi także strumieniowo, gdy token przychodzi pocięty na kawałki.

Agenci i narzędzia

Wyniki narzędzi w JSON-ie, kod, logi i pliki konfiguracyjne są maskowane wartość po wartości.

Dokumenty i maile

Faktury, umowy, CV i korespondencja, także tekst skopiowany z PDF-a albo Worda.

RAG i wyszukiwanie

Z tajnym kluczem token jest taki sam w każdym dokumencie i pytaniu, więc wyszukiwanie po zamaskowanym indeksie działa.

Haystack

Gotowe komponenty do potoków Haystacka 3: maskują dokumenty i pytania, a przywracają odpowiedzi, także strumieniowe.

Wiersz poleceń

polanon czyta tekst z argumentu, pliku albo wejścia i wypisuje go zamaskowanego, a mapowanie zapisuje osobno.

Ile tego łapie

Pomiar na danych, na których PolAnon nie był strojony, z Microsoft Presidio jako punktem odniesienia. Oba narzędzia mają ten sam polski model spaCy.

Zanim zaczniesz na tym polegać

Maskowanie to pseudonimizacja, a nie anonimizacja w rozumieniu RODO, i żaden detektor nie wyłapuje wszystkiego. Traktuj PolAnon jako zmniejszenie ryzyka, a nie gwarancję, i sprawdź go na własnych tekstach. Model zagrożeń opisuje, co jest objęte ochroną, a co pozostaje zadaniem Twojej aplikacji. Więcej o RODO w artykule ChatGPT, Claude i RODO.

Częste pytania

Czy PolAnon wysyła gdzieś moje dane?

Nie. PolAnon sam niczego nie wysyła: maskowanie odbywa się na Twoim komputerze albo serwerze. Do dostawcy modelu trafia tylko tekst z tokenami, który wysyła Twoja aplikacja albo bramka, a tabela tokenów zostaje u Ciebie.

Czy potrzebuję modelu językowego?

Nie. Identyfikatory, kontakty, adresy, sekrety i polskie imiona z nazwiskami rozpoznają reguły i listy. Model spaCy jest opcjonalny i dokłada miejsca, firmy bez formy prawnej oraz imiona spoza list.

Czy działa z modelem lokalnym, np. w Ollamie?

Tak. PolAnon maskuje tekst niezależnie od tego, dokąd go potem wyślesz: do OpenAI, Anthropic czy modelu na własnym serwerze. Z modelem lokalnym dane i tak nie wychodzą z firmy, ale maskowanie chroni je w logach i historii rozmów.

Czy poradzi sobie z tekstem skopiowanym z PDF-a albo Worda?

Tak. Litery zapisane jako litera i osobny znak diakrytyczny, spacje niełamiące, półpauzy w numerach i niewidoczne znaki o zerowej szerokości nie ukrywają wartości przed regułami. Samych plików PDF PolAnon nie czyta: dostaje tekst.

Czym różni się od Microsoft Presidio?

Presidio jest ogólne i wielojęzyczne. PolAnon jest pisany pod polskie dane: sprawdza sumy kontrolne PESEL-u, NIP-u i IBAN-u, rozpoznaje imiona w każdym przypadku i przywraca dane w odpowiedzi modelu, także strumieniowej. Na polskich danych maskuje więcej przy sześć razy mniejszej liczbie fałszywych alarmów.

Ile to kosztuje?

Nic. PolAnon jest otwartym oprogramowaniem na licencji MIT, także do użytku komercyjnego.
