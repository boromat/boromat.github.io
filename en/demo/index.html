You see

  • Nothing is sent anywhere. Once the demo has loaded, you can turn off the internet and keep masking.
  • The browser runs the rules only, without the spaCy model. On public Polish text they mask 51% of the values whole instead of 71% with the model, so place names, names off the list and unusual names can slip through.
  • The data in the examples is made up. Token names are Polish: OSOBA means person.

Use it yourself.

PolAnon is a Python library with no dependencies in its core. With the spaCy model it also finds places and unusual names.

pip install polanon
